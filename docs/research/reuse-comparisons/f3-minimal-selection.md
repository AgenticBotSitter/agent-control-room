Direct fit has actual required text/table/code behavior and fewer host interfaces;
Desktop offers richer controls but needs native/media and shared-state changes;
WebUI's selected test has unresolved partial behavior and different shell coupling.
Maintenance ranges overlap: lock/source evidence is not an advisory/upgrade study.
These overlapping scores do not establish a quantitative cost winner. Selection
rests on demonstrated required behavior with the fewest host/authority changes.

Keep-current textarea has minimal dependency/rollback cost but fails the required
formatted reading responsibility; retain it as fallback, not the chosen rich view.
A new custom parser lacks a named capability that these maintained parsers cannot
provide, so custom parsing has no justified infrastructure exception. The minimal
new adapter is the chosen combination: explicit navigation/resource policy and
canonical identity belong to CR, Markdown parsing does not.

state. Protected attachment navigation, preview/download and streamed multi-agent
history remain required distinct work. No discarded feature is hidden by this
narrow selection. No schema migration or authority deletion; presentation rollback
restores plain text without altering stored evidence or review history.
