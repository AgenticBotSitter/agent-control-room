# Archived Control Room research — 2026-08-22

These files are preserved historical source material. They are not current instructions and are not independently authoritative.

Some recommendations in this directory were rejected, narrowed, or superseded after adversarial review and implementation evidence. In particular, do not treat an archived recommendation as permission to expose a dashboard, reuse a credential as identity, transfer a secret, select a dependency, execute a command, or alter production state.

Use this authority order:

1. merged code, schemas, migrations, and tests;
2. `docs/BUILD_STATUS.md`;
3. normative contracts and accepted ADRs;
4. `docs/CR3_ARCHITECTURE.md` and `docs/CR3_BUILD_PLAN.md`;
5. `docs/RESEARCH_SYNTHESIS_AND_BUILD_DECISIONS.md`;
6. this archive.

The archive exists for provenance and later re-evaluation. It should not be loaded wholesale into an agent prompt. Select only the source needed for a concrete question and verify time-sensitive claims against current primary documentation.
