# Initial support matrix

This table distinguishes what the public source can do from what has been physically
qualified. “Planned” is not a compatibility claim.

| Environment / component | Current status | Supported scope | Still required |
| --- | --- | --- | --- |
| Linux server | Prepared/rehearsed, release candidate not accepted | Build and disposable compiled tests; private PostgreSQL design | Corrected release package, exact notices, persistent database/supervisor, restore/update and private ingress acceptance |
| macOS contributor | Tested for source work | Frozen install, type/component/build tests; disposable demo | No production server claim; owner-attended native connector qualification remains separate |
| Windows contributor | Partial evidence | LF checkout policy and disposable demo/worker-oriented source work | Three POSIX custody/server gates remain; no Windows production server support |
| Browser | Source/fixture tested | Protected project, task, result/review, Idea Lab/news and attention panels | Actual product wide/360px, keyboard, history/reload and two-configuration acceptance |
| Hermes via hermes-gpt | Source-inspected conditional target | FastMCP continue/status/result shapes selected | Actual unmodified interface fit, busy/lost-submit/truncation/restart-orphan tests; no cancel/replay/usage claim |
| Codex App Server | Exact selected-package schema plus earlier bounded evidence | Parent-owned stdio direction; pinned `thread/read(includeTurns: true)` request/response projection; start/events/interrupt concepts | Native read-only restart test, trusted identity/admission and canonical task/result wiring |
| Herdr | Optional/deferred | Operator-installed read-only pane observations | Selected-host native isolation and lifecycle qualification; never task authority |
| Cloudflare Access profile | Implemented policy shape, deployment-specific acceptance separate | Signed RS256 assertion, issuer/audience/session and exact-origin checks | Generic provider profiles and live direct-origin/MFA-policy acceptance |
| Injected RS256 gateway profile | Source/fixture tested, not operator-deployable | Fixed server-selected header plus issuer/audience/subject mapping; same local authorization | Safe operator key source/profile wiring and live direct-origin/MFA-policy acceptance; not OIDC discovery |
| Idea Lab and news | Substantial synthetic/disposable integration | Saved discussion/promotion and attributed collect/read/research-draft flows | Real participant task execution and common result/review path |

The initial release targets a Linux private server with browser clients and separately
installed Mac/Linux workers. Windows remains a contributor/demo and future worker target
until its exact worker path passes. Every connector publishes its actual harness version,
capabilities and unsupported operations; “any harness” means a stable extension contract,
not an assertion that every harness already works.
