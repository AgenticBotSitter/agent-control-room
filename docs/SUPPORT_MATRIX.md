The first operational multi-computer release targets a Linux private server with browser
clients, Linux Codex execution and separately installed Hermes workers on qualified hosts.
In parallel, **This computer** is a first-class installation choice: it keeps the same
database, scheduler and lifecycle, but has not yet passed its physical local-worker
proofs. macOS remains a supported contributor/browser environment; local Codex execution
is not a claim until its separate custody proof passes. Windows remains a contributor/demo
and future worker target until its exact worker path passes. Every connector publishes its
actual harness version, capabilities and unsupported operations; “any harness” means a
stable extension contract, not an assertion that every harness already works.
