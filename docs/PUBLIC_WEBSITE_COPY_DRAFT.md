## Agent Control Room

### One place for your projects and AI agents

We’re building a self-hosted workspace where different AI agents can work together
across your projects and machines—with clear permissions, visible progress and results
you can review.

Each project gets its own space. Follow tasks, collect files, see what needs your
attention, and archive completed projects without losing their history.

## What we’re building

- Project pages for tasks, progress, results and decisions.
- Connections to different agent runtimes, starting with Hermes and Codex integration work.
- Continuous work pickup within project permissions and resource limits.
- An Idea Lab for comparing ideas with several agents and turning promising ideas into projects.
- Optional news and research workflows that turn articles into useful agent tasks.
- Recovery, review and update tools for dependable everyday use.

These are the product goals, not a claim that every feature is ready.

## Built in the open, one working piece at a time

Agent Control Room is in pre-alpha. The public source release is being prepared.
Core components and simulated workflows have automated tests, but live multi-machine
operation, contributor installation and the complete interactive demo are not yet accepted.

We reuse established open-source components where they fit and preserve their licenses
and attribution. We build the connections and project-specific behavior needed to make
them work together.

## Help shape the project

We welcome help with usability, accessibility, documentation, testing, runtime adapters
and optional project workflows. The GitHub roadmap will explain how the pieces connect
and which tasks are ready to take on.

Contributions use ordinary issues and pull requests. You won’t need access to the
maintainer’s machines, credentials or private project records. Every change is reviewed
before it is integrated. Agent-assisted contributions are welcome, with the same
testing, licensing and review responsibilities as any other contribution.
