# Agent Control Room

A self-hosted workspace for coordinating AI agents across projects and machines.

Give each project its own space, assign work to suitable agents, follow progress,
collect results and review what happens next—without manually relaying every message.

## Status

Pre-alpha. We are preparing the source and contributor setup for an Apache-2.0
release. This repository is currently an introduction, not an installable release.
No production-ready or live multi-machine capability is promised yet.

## What we are building

- Separate project pages with tasks, files, progress and approvals.
- Hermes and Codex integrations first, with room for other agent runtimes.
- Bounded task pickup, reviewed results and visible recovery after interruptions.
- Idea discussions that become projects, and research that becomes useful work.

We plan to welcome substantial contributions in usability, accessibility, testing,
documentation and runtime adapters. Setup instructions, a roadmap and scoped work
packages will follow the source release. Please wait for those before starting code
contributions. Changes will be reviewed before integration.

GitHub Actions is currently disabled. We intend to run checks locally and batch
meaningful changes to conserve hosted CI minutes.
